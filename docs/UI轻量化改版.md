# UI 轻量化改版

产品目标：快捷键唤起 → 框选 → 原地标注 → 复制或保存后退出。

## 本轮变化

- 将 960 × 660 的工作台改为 380 × 420 的截图面板，移除宣传预览、首页侧栏、示例按钮与图片导入入口。文件菜单仍支持打开已有图片，未删除既有编辑能力。
- 面板显示区域、窗口、全屏截图及实际配置的快捷键；保留权限和快捷键异常提示。
- 悬浮工具栏首选宽度从 900 调整至 664，移除图标旁的常驻快捷键小字，快捷键保留在悬停提示中。
- 结束按钮直接显示当前完成动作；提取文字、贴图、重做、重选进入更多菜单。窄屏时逐级收拢标注工具，取消及结束按钮保持直接可用。
- 工具属性按需展开，增加线宽/字号数值；设置使用统一侧栏、标题和内容容器。
- 面板、设置、工具栏和已有图片编辑窗口统一使用系统语义色，取消强制浅色。
- 截图会话、坐标映射、原图、完成策略和持久化结构未修改。
