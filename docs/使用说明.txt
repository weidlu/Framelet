拾影 · Framelet 0.3.1 预览版

要求：macOS 14 或更高版本。

安装：将 Framelet.app 拖到 Applications 文件夹，再从 Applications 打开。

截图：
Control + Option + 4：区域截图。拖动框选，松开鼠标后在选区下方显示操作工具栏，Esc 取消。
Control + Option + 3：全屏截图，截取鼠标所在的屏幕。
区域截图启动时显示长十字线和像素放大镜；单击选中鼠标下窗口，按住拖动则手动框选。
窗口截图也可在菜单栏单独选择。
快捷键可在设置中修改；Option+A 等组合可用，系统或其他程序占用时会提示冲突。

首次截图需要系统屏幕录制权限。请在系统设置的隐私与安全性中允许拾影；若系统提示重启应用，请退出并重新打开。

截图后无需打开编辑窗口：在浮动工具栏选择工具，直接在选区上标注。
选区左上角的尺寸旁可拖动圆角滑块；最左边为直角。圆角截图的 PNG 和剪贴板图像保留透明角，JPEG 不支持透明角，会以白色填充。圆角大小可在设置中调整，并会记住上次选择。
Enter 或右侧完成按钮执行设置中的完成动作（复制、保存、保存并复制、贴图）并退出截图；「贴图」直接创建置顶窗口。
工具栏默认在选区下方；底部空间不足时放在上方，全屏选区时放在屏幕内。
移动选区工具可拖动选区或八个手柄调整范围；标注使用全图坐标，改选区不会拉伸标注。
瞄准时方向键逐像素调整，Shift+方向键每次 10 像素；空格设起点，方向键调整终点，Enter 选定。
选定后切回移动选区工具：方向键移动 1 像素，Shift 移动 10 像素；Option+方向键调整右边/下边，支持 1×1 像素选区。
这些按键不会接管正在编辑文字的输入框。
「重新选择」会清空当前选区和标注，重新框选。
文字工具在选区内点击后直接输入，Enter 确认文字，Esc 取消文字。
从文件打开的图片仍使用独立编辑窗口。
敏感内容请使用「遮挡」；马赛克不保证隐私内容无法被推断。
Command + Z 撤销标注；Shift + Command + Z 重做。
Command + C 复制合并图片；Command + S 保存 PNG 或 JPEG。
「提取文字」在本机识别中文和英文，可编辑、复制结果。
「贴图」将当前画面置顶，可移动、缩放和关闭。

隐私：图片不自动保存，不自动上传。仅在你选择保存时写入指定文件。
复制图片或文字会使用系统剪贴板；其他应用及系统通用剪贴板可能读取或同步剪贴板内容。
关闭主窗口后仍在菜单栏运行。Command + Q 完全退出。

取色：尚未选定区域时，放大镜显示原图像素的 sRGB HEX/RGB。G 复制 HEX，R 复制 RGB，不结束截图。
延时：菜单栏「延时截图」可选 3/5/10 秒，倒计时可取消；到时进入区域截图。
长截图：框选内容后，从工具栏「更多」选择「长截图 · 向下滚动拼接」（请在标注前开始）。
进入后向下滚动原页面，侧边预览自动增长，不需要每次停稳或估算半屏。可暂停、继续、取消，完成按钮遵循设置中的完成动作。
若失去可靠重叠会提示减速或向上回到已截末尾，已有内容保留，不会强行拼接。当前仅支持纵向滚动；大片空白、重复图案、视频和持续动画可能无法匹配。固定页头页脚只处理边缘的小范围区域；横向拼接和多滚动容器联动尚不支持。
长图上限为 30000 像素高或 4000 万像素总面积，达到上限后请分段截取。

这是预览版。录屏、翻译和自动更新尚未包含。
