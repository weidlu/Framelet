拾影 · Framelet 0.2.0 预览版

要求：macOS 14 或更高版本。

安装：将 Framelet.app 拖到 Applications 文件夹，再从 Applications 打开。

截图：
Control + Option + 4：区域截图。拖动框选，松开鼠标后在选区下方显示操作工具栏，Esc 取消。
Control + Option + 3：全屏截图，截取鼠标所在的屏幕。
窗口截图：在主界面或菜单栏中选择「窗口截图」，再选择目标窗口。

首次截图需要系统屏幕录制权限。请在系统设置的隐私与安全性中允许拾影；若系统提示重启应用，请退出并重新打开。

截图后无需打开编辑窗口：在浮动工具栏选择工具，直接在选区上标注。
Enter 或「完成」复制图片并退出截图；「贴图」直接创建置顶窗口。
工具栏默认在选区下方；底部空间不足时放在上方，全屏选区时放在屏幕内。
未标注时可拖动选区或四角调整范围，标注后可选择指针工具移动整个画面。
「重新选择」会清空当前选区和标注，重新框选。
文字工具在选区内点击后直接输入，Enter 确认文字，Esc 取消文字。
从文件打开的图片仍使用独立编辑窗口。
敏感内容请使用「遮挡」；马赛克不保证隐私内容无法被推断。
Command + Z 撤销标注；Shift + Command + Z 重做。
Command + C 复制合并图片；Command + S 保存 PNG 或 JPEG。
「提取文字」在本机识别中文和英文，可编辑、复制结果。
「贴图」将当前画面置顶，可移动、缩放和关闭。

隐私：图片不自动保存，不自动上传。仅在你选择保存时写入指定文件。
复制图片或文字会使用系统剪贴板；其他应用及系统通用剪贴板可能读取或同步剪贴板内容。
关闭主窗口后仍在菜单栏运行。Command + Q 完全退出。

这是预览版。长截图、录屏、翻译和自动更新尚未包含。
