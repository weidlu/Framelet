# 发布检查

当前定位：官网下载安装的独立 macOS 截图工具，0.3.0 预览版。不是 iShot 修改版。

## 分发

- 确认工作名「拾影 / Framelet」及正式 bundle ID，核验名称、域名和品牌可用性。
- 验证 Developer ID Application 签名、hardened runtime，以及完整 `.app` 签名。
- 构建 Universal 2；在实际 Intel 和 Apple Silicon Mac 分别验收。
- 向 Apple 公证服务提交安装包，确认状态 Accepted，附加并验证票据。
- 在另一台干净的 Mac 上，通过浏览器下载带 quarantine 的 DMG，验证 Gatekeeper 和首次安装；本机直接启动不能替代。
- 补充开发者主体、支持联系方式、最终隐私政策和版本说明。
- 确认下载域名、HTTPS、安装包 SHA-256，用户授权后再发布。

## 功能验收

- 全新权限、拒绝权限、撤销权限、授权后重启；均给出明确恢复路径。
- 不同缩放倍率、外接显示器、负坐标显示器、切换 Spaces、屏幕方向变化。
- 区域、全屏、窗口截图；窗口消失或最小化时错误可恢复；Esc 取消后恢复原窗口。
- 中英 OCR；没有文字、透明图片、超大图片、旋转 EXIF 图片。
- 编辑工具、撤销重做、保存取消、不保存关闭、退出保护、窗口重复打开。
- 马赛克之后覆盖遮挡、遮挡之后叠加马赛克，导出不能恢复先前遮挡内容。
- 复制及保存后的像素与预览一致，PNG/JPEG 可被其他软件读取。
- 全局快捷键被占用时，菜单栏操作可继续使用。
- VoiceOver、键盘导航、不同屏幕大小和系统字体设置。

## 后续迭代

长截图、逐像素选区、延时、取色、快捷键自定义已实现；录屏与音频、自动更新不在当前版本范围。未实现功能不在官网宣传为已提供。公开发布前明确测试状态与已知限制。

## Mac App Store 可行性

截图类工具可以通过 Mac App Store 分发，当前版本尚未制作商店包，不能直接上传 DMG 作为商店版。

待办：启用并验证 App Sandbox；为用户选择的保存目录使用 security-scoped bookmarks，不能依赖任意绝对路径；在沙盒下验收 ScreenCaptureKit、Carbon 全局快捷键、SMAppService 登录项、剪贴板、Vision OCR；准备商店分发证书/配置与上传包；核对隐私表、截图、支持页面、审核说明及名称可用性。

不需要为了走 App Store 把 Developer ID 官网包的公证当作商店审核；两种分发渠道独立。最终是否通过由 Apple 审核决定，本轮不提交 App Store。

依据：
- https://developer.apple.com/app-store/review/guidelines/ （2.4.5，Mac App Store 沙盒要求）
- https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution
- https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype
