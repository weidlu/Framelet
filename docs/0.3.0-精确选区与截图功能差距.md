# 精确选区交互与 iShot 截图功能差距

日期：2026-10-27。范围：截图、标注、复制/保存、贴图及与截图直接相关的 OCR；录屏和录音不作为当前目标。

## 本轮交互

- 启动进入瞄准阶段：保留冻结桌面的原始亮度和位置，显示贯穿当前显示器的横纵辅助线、鼠标附近的像素放大镜；窗口感应只画细边框，不提前显示粗选框、尺寸和遮罩。
- 放大镜读取原始 CGImage 的 15×15 像素，按每格 8 个逻辑点放大，关闭插值；中心像素有醒目标记，显示当前显示器内、左上原点的 X/Y 像素坐标。靠屏幕边缘翻转面板方向，原图外的网格留空而不移动中心。
- 单击选中鼠标下最前方窗口；按住拖动超过已有阈值则手动框选。拖动端点对齐原图像素边界。
- 松手确认后辅助线和放大镜退出，出现原有选区手柄、标注工具栏；回车完成、Esc 取消保留。重新选区重新进入瞄准。
- 在显示覆盖窗口之前准备其内容；背景保持原有全屏尺寸、不做动画缩放。

实现：`Capture.swift` 管理阶段，`PrecisionCaptureGuide.swift` 是不接收点击的装饰视图，`PixelInspection.swift` 统一取样、像素对齐和放大镜避让几何。放大镜移动不再取屏，也不重新合成整张图片。

## 验证

- `bash scripts/swift.sh run FrameletChecks`：33 项全通过。新增 Retina/1x 坐标、负坐标原点、像素边界到导出尺寸、四角取样中心、面板避让检查。
- release 构建通过，Developer ID 签名验证通过，替换 `/Applications/Framelet.app`；备份在 `work/build-archive/20261027-200732`。
- 真机屏幕录制权限下验证：初始十字线/放大镜/细边框；单击选窗→工具栏；拖动区域→工具栏；回车复制退出；Esc 退出。证据在 `work/precision-acceptance/`。
- 截图前设置窗口与启动瞄准后的同一窗口保持相同大小，匹配偏移 (712,216)。标题文字区域 400×130 像素平均通道差 0.283、最大差 9，纯色背景 RGB(30,30,30) 不变；不是逐像素完全相同，不将不同取图路径的色差冒充缩放问题。
- 离屏调用实际 `PrecisionCaptureGuide.draw`，用上绿下红右蓝的不对称原图确认放大镜方向、网格和中心像素。脚本/图片在 `work/precision-acceptance/render-check/`，不读取屏幕、生成窗口或发送输入。
- 限制：未录制高帧率视频证明所有启动瞬间均无闪动；多显示器混合缩放仍需实机验收。当前仍保留最小选区和拖动阈值，不能将像素网格显示等同于已经支持任意 1×1 像素小选区或键盘逐像素移动端点。

## 截图功能差距及建议顺序

对照依据：
- iShot 官方介绍：https://better365.cn/ishot.html
- 官方 App Store 描述：https://apps.apple.com/cn/app/id1485844094
- 当前 Framelet 工作区源代码；不是对所有 iShot 菜单的逐项实测。

| 能力 | Framelet 当前状态 | 后续优先级 |
| --- | --- | --- |
| 长十字线、像素放大镜、单击选窗/拖动框选 | 本轮已实现；键盘逐像素微调、任意小选区仍缺 | P0：继续打磨精确选择与混合缩放 |
| 区域/全屏/单窗口/上次区域，原位标注，复制/保存 | 已有基本闭环 | P0：持续回归焦点、快捷键、中文输入、取消与确认 |
| 长截图/滚动拼接 | 未实现 | P1：下一项主要截图能力，处理重叠、固定页头和重复内容 |
| 延时截图 | 未实现 | P1：捕获菜单、悬浮提示等易消失内容 |
| RGB/HEX 取色及复制 | 未实现；目前放大镜只提供像素和坐标 | P1：可复用本轮原图取样 |
| 多窗口组合截图 | 未实现；当前只选一个窗口或一个矩形 | P2 |
| 数字序号标注、丰富文字样式 | 未实现；已有箭头、矩形、椭圆、画笔、文字、马赛克和遮挡 | P2 |
| 贴图增强 | 仅基础置顶、移动/调整窗口；缺透明度、穿透、快捷缩放等丰富操作 | P2 |
| 圆角/阴影、带壳截图、外部编辑器衔接 | 未实现 | P3 |
| OCR 增强 | 有本地中英文识别；缺二维码、连续识别、去换行与翻译 | P3，按实际使用需求推进 |

本轮只实现精确选区交互，以上待办未自动扩成开发任务。保留其他任务尚未提交的工具栏、Views 和图标改动，未纳入本次提交。
