## 已修复的开发构建问题

开发时覆盖正在运行的应用二进制曾触发一次 macOS `CODESIGNING / Invalid Page` 终止。构建脚本现要求先退出已有应用，使用临时目录完整组装、签名和验证，再替换最终 `.app`；已重建并重新启动完成上述真实截图验收。没有以修改系统安全设置的方式处理此问题。
