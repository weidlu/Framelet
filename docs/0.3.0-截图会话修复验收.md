# 0.3.0 截图会话修复验收

2026-10-27，Apple Silicon，macOS 26.6.2。本轮由主代理直接修改、集成和验收；Pi 终端已停止，接手前代码保存在 `9bbffc6`。

## 根因与修复

- 不透明标注画布盖住了父视图绘制的选区边框。新增独立透明边框视图，位于画布之上、工具栏之下，显示尺寸和八点调整手柄；全屏选区边框向内绘制。
- 原来整个遮罩都注册十字光标，选区外点击还会开始重新框选。现在只在初始框选时使用十字；确认选区后，框外为箭头、移动选区为张手、拖动为握手、手柄为缩放。工具栏使用箭头；文字和绘制工具在选区内使用各自光标。只有明确点击“重新选择”才重选。
- 结束时丢弃窗口光标区域、移除事件监视器并恢复箭头。合并重复的 Esc 事件监视器，以同一取消入口处理截图会话；文本编辑和系统模态面板保留自己的键盘语义。
- 标注画布裁剪到选区，拖出边界的坐标夹到选区边界；文字输入框限制在画布内，字号按实际倍率换算。
- 独立窗口图按完整窗口目标矩形绘制再裁剪，避免部分越界时拉伸。合成失败明确报错并取消，避免静默输出错误桌面。
