# 拾影隐私说明（发布草稿）

适用版本：0.1.0–0.2.0。最后更新：2026-10-27。

拾影在用户主动发起截图时使用 macOS ScreenCaptureKit 读取选定屏幕或窗口。图片编辑和 Apple Vision 文字识别在本机完成。应用不含账号、广告、第三方分析、遥测或网络请求代码，不向开发者服务器发送截图、识别文字或使用记录。

截图与导入图片在进程内存中编辑。用户明确点击保存后，图片写入用户选择的文件。用户明确复制后，图像或文字写入 macOS 剪贴板；其他应用及 Apple 通用剪贴板的访问或同步由用户的系统设置控制。

应用不请求麦克风、摄像头、通讯录或定位权限。系统屏幕录制权限可在系统设置中撤销。卸载应用不会自动删除用户自行导出的图片。

操作系统可能按系统诊断和分析设置处理进程日志和崩溃报告，这不等于拾影自行收集数据。开发者不得将系统权限或 Apple 签名、公证误称为绝对隐私保证。

发布前必须补充运营主体、支持邮箱或支持页面以及适用地区所需的政策内容。本草稿尚不能作为对外完成版隐私政策。
