# 拾影 Framelet

**拾影（Framelet）** 是一款纯原生开发的 macOS 精确截取与就地标注工具。它以「像素级精度、操作流不被打断、数据纯本地运行」为设计核心，致力于提供轻巧克制、无广告、零云端上传的桌面截图标注体验。

> **当前阶段**：0.3.0 预览版（Universal 2 架构，原生支持 Apple Silicon 与 Intel Mac，要求 macOS 14.0+）。通过官网独立分发，公证流程准备中。

## 面临问题

在日常 macOS 桌面办公、设计评审与开发调试中，现有的截图工具常常走向两极：
1. **系统原生截图**：简单纯净，但在需要微调边界、精准提取色值、或者原地标注箭头/遮挡脱敏时，缺少灵活的即时辅助；
2. **常见的第三方商业截图软件**：体积日益庞大，捆绑复杂的录屏驱动、云端图床上传、甚至强制要求账户登录与广告推荐，带来了潜在的隐私安全顾虑与视觉干扰；且在截取长图时往往因为强制自动滚动或缩放算法导致导出的条带模糊失真。

## 解决方案

拾影采用原生 Swift 语言与 Apple 现代系统 API（ScreenCaptureKit 与 Vision 框架）独立重构打造：
- **原地操作流（In-situ Toolbar）**：框选完毕后直接在选区边缘呼出工具栏，不再弹出笨重独立的二级编辑大窗口；
- **像素级控制**：提供通贯全屏的长十字准星标尺与 8x8 放大镜，支持键盘方向键 1 像素步进微调；
- **高保真长图拼接**：连续高帧率捕获屏幕帧流，通过紧凑 RGB 行特征与原始像素验证完成拼接，侧边独立悬浮窗实时高清预览，并智能保留固定页头与页脚；
- **绝对的本地安全**：中英文文字提取（OCR）完全基于本机 Apple Vision 离线模型，截图数据单层重新编码合成，杜绝云端上传和脱敏图层被逆向还原的风险。

### 核心特性

- **1 像素级精准微调与取色**：支持长十字标尺与放大镜，按下 `G` 复制 HEX 颜色、按下 `R` 复制 RGB 颜色；支持方向键逐像素步进调整选区。
- **原位即刻标注**：选区内即时使用方框、圆圈、箭头、自由画笔、文字、马赛克与纯色遮挡工具，支持全套撤销重做。
- **连续滚动长截图**：在原应用或浏览器中自然向下滚动，侧边实时高清增长预览，修复早期版本条纹问题，智能识别视口顶部固定页头。
- **3/5/10 秒延时截图**：菜单栏提供倒计时延时捕获，倒计时面板淡出后再捕获屏幕，轻松截取浮动菜单。
- **离线 Apple Vision OCR**：在本地离线提取中英文字符，支持直接在选区内修改编辑与一键复制。
- **保持色彩的剪贴板与贴图**：支持直接写入无损 TIFF/PNG 剪贴板；支持将关键截图置顶贴在桌面上作为参考（Pin on screen）。
- **极简后台集成**：常驻系统顶部菜单栏，支持登录自启动与全局快捷键自定义。

## 产品设计原则与边界

拾影坚持诚实透明的原则，不做虚假卖点承诺：
- **不包含**：录屏与声音内录、机器多语言翻译、数字步骤序号、全自动机械滚动；
- **导出机制**：所有保存或复制的图像均为压平的单层位图，不支持再次打开工程文件对标注对象二次编辑，确保敏感信息经「遮挡」后不可逆。

## 技术栈与基础设施

- **客户端架构**：Swift、ScreenCaptureKit、Vision、AppKit、Universal 2 (arm64 & x86_64)
- **官网托管**：Cloudflare Workers Static Assets (发布目标: `https://framelet.slnt.dev`)
- **系统要求**：macOS 14.0 (Sonoma) 或更新版本
